How this works

A C++17 Windows tray app counts keystrokes and mouse/touchpad clicks with low-level hooks and samples the foreground app once a second, skipping idle and locked time. It stores per-minute counts in SQLite, and every 30 minutes publishes sanitised JSON (allow-listed app names, everything else is "Other") to the data branch of this site's repo via the GitHub API. This page is static and just reads that JSON. Source and architecture: BigBouncyBoii/portfolio_page.
